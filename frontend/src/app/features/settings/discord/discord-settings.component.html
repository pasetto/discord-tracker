Conexão Discord

Cadastre o bot que você criou no Discord Developer Portal , adicione-o ao seu servidor e escolha qual servidor monitorar.

1. Cadastrar bot

Use o mesmo aplicativo que já roda no outro sistema. Copie as credenciais no Developer Portal (OAuth2 → Client ID / Client Secret; Bot → Token).

Client ID: número longo (ex.: 1234567890123456789) — não é email.

Client Secret: em OAuth2 → Client Secret.

Bot Token: em Bot → Token (formato com dois pontos). Não confunda com Client Secret.
